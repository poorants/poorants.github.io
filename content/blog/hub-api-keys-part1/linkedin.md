API 키를 서버 한 대의 허브로 옮겼더니, 제 에이전트와 스크립트는 더 이상 진짜 키를 들고 있지 않습니다.

전에는 Cloudflare, B2, LinkedIn, 텔레그램 봇 같은 개인 API 키를 파일 하나에 모아 PC마다 사본을 두었습니다. 지금은 키를 허브 한 곳에만 두고, 에이전트와 스크립트에는 할 수 있는 일이 정해진 토큰 하나만 줍니다. 범위를 벗어난 요청은 허브가 403으로 막고 기록을 남기며, 키를 바꾸는 날에도 PC를 돌지 않습니다. 제 PC용 토큰처럼 아직 넓게 열어 둔 곳까지 실제 화면과 함께 정리했습니다.
