사내에서 따로 놀던 도구 세 개를 통합 MCP 하나로 묶었더니, 이슈 처리부터 배포와 문서화까지가 한 흐름으로 이어지기 시작했습니다.

이슈 관리, 파일 서버, 사내 위키 — 평소 일하며 손으로 오가던 시스템들입니다. 각각의 API 를 하나의 MCP 서버 모듈로 감싸 Claude Code 에 붙였습니다.

가장 크게 달라진 건 '오가는 노동'이 사라진 것이었습니다. 예전에는 이슈를 읽고, 코드를 고치고, 빌드해서 올리고, 처리 결과를 이슈에 적고, 개발 노트를 위키에 남기는 일을 시스템마다 옮겨 다니며 했습니다. 이제는 그 사슬이 채팅창 안에서 한 번에 흐릅니다. 이슈를 분석·수정하고, 배포가 끝나면 처리 내용과 경로를 이슈에 자동으로 코멘트로 남기고, 개발 노트까지 위키에 올라갑니다.

더 흥미로운 건 가능성 쪽이었습니다. 이 MCP 를 사용자 스코프에 한 번 셋업해 두니 모든 프로젝트에서 공통으로 잡혔습니다. 한 번 만든 파일 서버 MCP 는 전혀 다른 라이브러리로 구축한 테스트 서비스에 그대로 재활용됐고요. 도구를 한곳에 묶어 둘수록 새 일에 드는 품이 줄어드는, 복리 같은 구조였습니다.
