AI 에게 사내 배포를 맡기면서 가장 먼저 한 일은, 권한을 더 주는 게 아니라 막는 것이었습니다.

사내에서 쓰던 도구 몇 개 — 이슈 관리, 파일 서버, 위키 — 를 MCP 로 감싸 Claude Code 안에서 업무를 끝낼 수 있게 붙여봤습니다. 그런데 MCP 는 결국 AI 가 도구를 직접 쥐고 움직이는 구조라, 기존 배포 시스템을 통째로 만지게 둘 수는 없었습니다.

그래서 경로별로 권한을 갈랐습니다. 정식 릴리즈 경로는 읽기만, 쓰기는 테스트용 QA 전달 경로 한 곳에만. AI 가 파일을 올릴 수 있는 자리를 딱 하나로 좁힌 겁니다.

이슈를 가져와 분석·수정하고, 배포가 끝나면 처리 내용과 경로를 이슈에 자동으로 코멘트로 남기고, 개발 노트는 위키에 바로 올리는 — 이 과정을 MCP 한 모듈에 세 서비스로 묶어 정리했습니다. 사용자 스코프에 한 번 셋업해 두니 모든 프로젝트에서 공통으로 쓰이더군요. 다음은 유저 테스트 자동화를 노려볼 생각입니다.
